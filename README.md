# EDGEOS — Milestone 1

Pure-from-scratch Android launcher foundation. This source is independent of the Claude M1 source previously reviewed.

## Scope
- Android 8.1 / API 27 minimum
- Modern Android target
- Real HOME launcher activity
- PackageManager app discovery
- 4x5 home grid
- Dock
- Horizontal page swipe
- App launching
- Wallpaper is the launcher window background (system wallpaper remains visible where supported by the device)
- Layout persistence foundation
- Package install/remove/change refresh
- No INTERNET permission, ads, analytics, trackers, root, exploit, or hidden APIs

## Roadmap
M1 Foundation + Launcher → M2 Animation Engine → M3 Liquid Glass + Theme → M4 Folder + Widget → M5 Control Center → M6 Notification Center → M7 Spotlight → M8 App Library → M9 Dynamic Status → M10 Lock Screen Experience → M11 AssistiveTouch → M12 Capability + Compatibility → M13 Performance + Polish + QA.

M1 is intentionally not the final product.
